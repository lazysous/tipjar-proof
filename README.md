# Footy Tip Jar predictions (archived)

**This repository is archived and is no longer updated.** It holds the locked AFL predictions for rounds 0 to 3 of
the 2026 season (`predictions/2026/round-00` to `round-03`) and nothing after that. It is kept as a historical
snapshot, not as the record of our predictions.

**The record is the live accuracy page: https://footytipjar.com/season**

Every tip there is locked at kickoff and is not edited afterwards, and it is graded when the game ends. The page shows
the season totals and the round-by-round results. The 2025 backtest is at https://footytipjar.com/proof.
